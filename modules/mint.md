# Mint
 
Ubuntu-based — **all `apt` commands work here.**
 
 ### Mint tools
 
| Command | What it does |
|---|---|
| `mintupdate` | update manager |
| `mintinstall` | software manager |
| `mintdrivers` | driver manager |
| `timeshift-gtk` | snapshots — take one before risky changes |
| `sudo timeshift --create --comments "before update"` | snapshot from terminal |
 
### Cinnamon
 
| Command | What it does |
|---|---|
| `cinnamon --replace &` | restart desktop if frozen |
| `Ctrl+Alt+Esc` | restart Cinnamon by keyboard |
